# Documentation index

Every file under `doc/`, what it holds, and when to read it. File names are
relative to `doc/`. The first three rules files must be read at the start of
every task (`AGENTS.md`). `notes.md` must be read, and its tag quoted, at the
start of any task that writes or changes a spec. The others are read when the
task needs them.
