# Documentation index

Every file under `doc/`, what it holds, and when to read it. File names are
relative to `doc/`. The first three rules files must be read at the start of
every task (`AGENTS.md`). `notes.md` must be read, and its tag quoted, at the
start of any task that writes or changes a spec. The others are read when the
task needs them.

## Instructions for agents: updating this file

Update this file in the same change that adds, renames, deletes or substantially
changes any file under `doc/`. A change that does not update it is incomplete.

The file must hold:

1. **One row for every file under `doc/`, including this one, and no others.**
   List only files that exist. Planned files (for example the planned specs
   listed in `specs/README.md`) do not get a row until they are created. Do not
   list files outside `doc/`.
2. **The columns, in this order, with no empty cell:**
   - **File:** the path relative to `doc/`, written as a markdown link to the
     file.
   - **Summary:** what the file contains, in one or two sentences, naming its
     main topics. Say whether it is normative (the rules) or design and
     reference material (the specs) when that is not obvious. Describe the
     content as it is now: re-read the file before you write or change its row.
   - **Read it when:** the concrete situations or tasks in which a reader
     should open it. Say if it must be read at the start of every task. Do not
     write "for information" or "for reference".
3. **Rows sorted** with this file first, then `overview.md`, then `vision.md`, then `roadmap.md`, then `notes.md`, then `adr/`, then `rules/`, then `specs/`, and
   alphabetically by path within each directory, except that `specs/README.md`
   comes first among the specs, followed by the spec files, and the evidence
   and reference files last.
4. **The intro paragraph kept true.** If the set of files that must be read at
   the start of every task changes, update the intro and `AGENTS.md` together.
5. **Rows removed or corrected when a file is deleted, moved or its purpose
   changes.** A renamed file keeps one row under its new name, and links to the
   old name elsewhere in `doc/` are updated.

Before you finish, check the table against the directory:

```sh
find doc -type f | sed 's|^doc/||' | sort
```

Every path printed must appear in the File column, and every path in the File
column must be printed.
